# DTCG Resolver example

[简体中文](README.zh-CN.md)

This example combines a foundation set with a DTCG 2025.10 `theme` modifier. The config selects the dark input and emits CSS from the resulting typed graph.

```bash
vp run build
```

Change `resolver.input.theme` in `tokenc.config.ts`, or run the root CLI with `--theme light`, to select another resolution.
